# .github

Organization-wide GitHub configuration for [Mustry Academy](https://github.com/Mustry-Academy).

- [`profile/README.md`](profile/README.md): the organization profile shown on
  [github.com/Mustry-Academy](https://github.com/Mustry-Academy).
- [`SECURITY.md`](SECURITY.md), [`CONTRIBUTING.md`](CONTRIBUTING.md),
  [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) and
  [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/): default community health files for every
  Mustry-Academy repository that does not define its own.
